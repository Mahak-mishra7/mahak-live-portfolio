# Mahak Mishra - Spider-Verse Portfolio 🕷️

> **"Every universe has a hero."**
> A modern, responsive personal portfolio website for **Mahak Mishra** (BTech CSE, Aspiring Software Engineer) built with a futuristic Ghost-Spider / Spider-Verse inspired aesthetic.

---

## 🚀 Live Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 6
- **Styling**: Modern Responsive CSS3 (Custom Properties, Halftones, Neon Glows)
- **Icons**: Lucide React
- **Typography**: Orbitron & Inter (Google Fonts)

---

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone <YOUR_REPOSITORY_URL>
cd mahak-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Visit `http://localhost:3000` in your browser.

### 4. Build for production
```bash
npm run build
npm run preview
```

---

## 📝 Customization Placeholders

To personalize your deployment links and social frequencies, replace the placeholders:
- `src/components/Contact.jsx`: `YOUR_GITHUB_URL`, `YOUR_LINKEDIN_URL`, `YOUR_EMAIL`
- `src/components/Missions.jsx`: `YOUR_PROJECT_URL`, `YOUR_GITHUB_URL`
